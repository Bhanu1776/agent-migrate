agent-migrate

Move your coding-agent setup from one harness to another with one command. It does a dry run first, shows a gap report, and is safe to run again.

How it works

Readerclaude-code
codex
→
Neutral bundleinstructions · skills · prompts · MCP · memory · hooks · guards · chats
→
Writerpi · oh-my-pi
prime-agent
opencode · hermes

Each harness needs one reader and one writer, not a converter for every pair. To add a harness, write one file and add one line in cli.py.

Use it

# 1. See the plan. This writes nothing.
./agent-migrate claude-code pi --dry-run

# 2. Try it on a scratch folder, then check it with pi's own loader
./agent-migrate claude-code pi --target /tmp/pi-test
node tests/verify_pi_target.mjs /tmp/pi-test ~/some/repo

# 3. Apply it for real (pi's default dir ~/.pi/agent)
./agent-migrate claude-code pi
./agent-migrate codex pi          # you can run it again; each source keeps its own block

# Only some parts
./agent-migrate codex pi --only skills,mcp,memory

# Other targets: opencode · oh-my-pi · prime-agent · hermes
./agent-migrate claude-code opencode --dry-run

What moves where (→ pi; other targets use their own native equivalents)

PartFromBecomes
InstructionsCLAUDE.md · AGENTS.mdA marked block in AGENTS.md. Your own text stays, and the old file is backed up.
Skillsskills/, plugin skillsA symlink, only if pi cannot see the skill yet. Skills that were "off" stay off.
Promptscommands/, prompts//name commands. Plugin commands get a prefix (/codex-rescue).
MCP.claude.json · config.tomlmcp.json (mode 0600), plus pi-mcp-adapter.
Memoryprojects/*/memory · memories/memory/<project>. It goes into the prompt on every turn.
Hookssettings + plugin hooks, notifyThe bridge extension runs them. They get JSON on stdin, and exit 2 blocks the action.
Guardsdeny/ask rules, soft_deny, .rulesBefore a matching bash command, pi asks you, or blocks it if no one can answer.
Chatstranscripts, rolloutspi sessions for /resume. Only the text and short tool-call lines are kept.

Promises (tested)

  • A dry run writes nothing.
  • A second run adds nothing new. No chats or blocks are duplicated.
  • Secrets stay in 0600 files and never show on screen.
  • It never deletes anything you wrote. It makes backups with a timestamp.
  • It never copies logins, account connectors (Slack, Gmail…), or keybindings. The gap report lists them for you.

Before you trust it

  1. Read the "not migrated" list at the end of every run. That list is your to-do list.
  2. If you already set up the target by hand (for example your own memory or hook extension), remove it, or those things run twice.
  3. Plugin hooks are run as they are. Check the hooks rows in the dry run first.
